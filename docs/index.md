# Task Manager

A cross-platform task manager for Android, iOS and Windows, written in F# with Fabulous on
.NET MAUI 10. It is meant as a starting point for a real app: MVU state in a plain library,
unit tests, pluggable sign-in and an authenticated HTTP client.

- [Architecture](architecture.html): projects, MVU, commands, navigation, adding a feature
- [Authentication](authentication.html): providers, Cognito setup, custom providers, sessions
- [Views and controls](views.html): Fabulous builders, the window, a custom SkiaSharp control
- [Building and running](building.html): prerequisites, platforms, this site, CI

The API reference covers `TaskManagerApp.Logic`.
